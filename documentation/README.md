# Documentation references

This directory contains catalogue records for historical documentation relevant to the PDP-11 and its peripherals.

The initial entries are **external references**, not copies of the documents. They use the PCjs PDP-11 library as a discovery/index page and, where PCjs explicitly lists one, record the source link shown by PCjs.

## Why these are references

PCjs explains that its library combines material from several sources, including Bitsavers, other archives, and the maintainer's own collection and scans. PCjs also notes that provenance was not consistently recorded for every item and that a displayed source link is not guaranteed to be definitive.

For that reason, this repository does not mirror the PDFs or imply that their redistribution rights have been verified. Follow the links to consult the material at its current host. Before adding a document file to this repository, establish and record a suitable redistribution basis or permission.

## Catalogue

See [catalog.json](catalog.json). Each entry records bibliographic details and external discovery/source links. Missing source links mean that PCjs does not display a separate source link for that item on its PDP-11 page; they do not mean that PCjs is the rights holder.
