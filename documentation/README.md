# PDP-11/70 Reference Library

A curated technical library for the **PDP-11/70** implemented by [yaPDP](https://amesk.github.io/yaPDP/pdp11.html), together with the peripherals and software ecosystem that make the machine useful.

This is deliberately not a general DEC archive. PDP-8, PDP-10 and unrelated computer families are out of scope.

## Collection

- **PDP-11/70 hardware** — processor handbook, KB11-C internals, installation and maintenance, memory and console options.
- **Peripherals and UNIBUS** — device families, terminals, paper tape, printers, disks, tape drives and communications.
- **Operating systems** — RT-11 installation and user documentation.
- **Programming** — BASIC-11 and the wider PDP-11 software ecosystem.
- **Diagnostics** — service documentation and diagnostic references.

The catalogue records edition, document number where known, archival source, topics and a short description. Search it by model, device, operating system or subject.

## Access and provenance

The PDFs are linked at archival hosts such as Bitsavers and are **not mirrored in this repository**. Links do not imply that yaPDP-goodies owns the scans or grants a redistribution licence. Original DEC copyright notices remain part of the documents.

## Scope

The purpose is to support research and hands-on exploration of the PDP-11/70 implemented by yaPDP. Related PDP-11 models may appear only where they provide useful comparative or peripheral documentation. PDP-8 and unrelated families are intentionally excluded.
